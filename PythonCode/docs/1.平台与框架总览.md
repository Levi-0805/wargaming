# 1. 平台与框架总览

## 1.1 平台职责

CSSIM 由 UE 可视化仿真端和 Python 算法端组成。UE 负责场景、实体、物理、动作执行和胜负判定；Python 负责读取态势、运行红蓝算法、生成动作、训练模型和记录日志。二者通过 gRPC 通信，业务数据以 UTF-8 JSON 放在 gRPC 消息中传递。

Python 端坚持四项边界：单环境、单事件循环、每帧串行交互、每个战斗实体每帧只选择一个逻辑动作。`-s` 只是兼容 UE 启动参数，不会创建守护进程。

## 1.2 目录职责

```text
PythonCode/
├─ main.py                 命令行入口
├─ cssim/                  发布框架，不建议选手直接修改
│  ├─ algorithms/          规则与强化学习公共生命周期
│  ├─ environment/         状态解析、阵营隔离和队伍态势对象
│  ├─ protocol/            动作对象、动作集合和事件解析
│  ├─ runtime/             算法加载、逐帧调度和特殊动作执行
│  └─ transport/           gRPC 通信
├─ AlgTemplate/red|blue/   UE 创建算法时复制的红蓝模板
├─ TeamAlg/                UE 生成或保存的队伍算法
├─ TaskConfig/cssim/       UE 生成并传给 main.py 的 JSONC 配置
├─ docs/                   发布文档
└─ tests/                  框架回归测试
```

`TaskConfig`、`AlgTemplate`、`TeamAlg` 的位置和职责是 UE 的固定约定。UE 创建算法时按阵营复制 `AlgTemplate/red` 或 `AlgTemplate/blue` 到 `TeamAlg/<队伍ID>`；开始仿真时生成配置并执行 `main.py -c <配置路径> -s`。

## 1.3 两类算法

- 规则模式继承 `RuleAlgorithm`，实现 `decide(state)`，直接为每个本方实体选择一个动作对象。
- 强化学习模式继承 `ReinforcementAlgorithm`，自行定义态势、离散动作集合、网络、经验和训练过程。框架不要求使用 DQN；DQN 模板只是完整参考实现，QMIX、PPO 等也可以建立在同一生命周期上。

红方任务是进攻蓝方指挥所；蓝方任务是保护一个或多个指挥所。框架始终保留全部有效 `key_objects`，不把场景写死为单指挥所。

## 1.4 安全视图

运行器内部拥有完整 `SimulationState`，选手只能得到本阵营的 `TeamState`。己方实体提供经过审查的自身信息；敌方只通过 `visible_opponents` 暴露脱敏对象。局部决策应使用 `state.perceived_opponents(agent)`，不能假定每个 Agent 都看见全队已经共享的全部敌方。

## 1.5 一次开发任务会经过哪些文件

选手通常只需要处理自己的队伍目录：

```text
UE中创建算法
  → UE复制对应阵营AlgTemplate
  → 得到TeamAlg/<队伍ID>/
  → 在Algorithm/中修改规则或强化学习实现
  → UE生成TaskConfig并启动main.py
  → 框架加载RLAgentAlgorithm入口
  → 日志写入logs/<本次启动时间>/
```

不要直接在 `cssim/runtime` 中写战术，也不要在 `transport` 中拼动作。规则策略属于 `RuleAgentAlgorithm.py`；强化学习的态势、动作集、网络和训练属于强化学习实现文件；`RLAgentAlgorithm.py` 只承担稳定入口和配置解析。

## 1.6 核心对象之间的关系

```text
UE原始JSON
  → SimulationState（框架内部全场快照）
      → TeamState(team=0，红方) → 红方算法 → 红方动作
      → TeamState(team=1，蓝方) → 蓝方算法 → 蓝方动作
  → 按各自state.agents动作行关联执行者
  → 为每条字符串编码本回合executor UID
  → UE按字符串中的UID定位并执行
```

`Entity` 表示士兵、无人狗、无人车或无人机等具有普通动作位置的实体；`commanders` 表示场景指挥员，不进入普通动作数组；`KeyObject` 表示指挥所等战略目标。指挥员和指挥所不是同一类对象，不能混用。

本方 `state.agents[i].team_index == i`，这里的 `team_index` 是 Python 动作行号。UE 字段 `indexInTeam` 则是实体当前上级 UID，与动作行号无关。
